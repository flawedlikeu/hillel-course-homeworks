Автоматизація фронтенду з Gulp

Цю сторінку зібрано за допомогою Gulp: SCSS компілюється в CSS, отримує вендорні префікси, форматується та мінімізується, а браузер оновлюється автоматично під час розробки.

Що вміє збірка

Можливості

🎨

SCSS

Змінні, міксини, вкладеність і модулі @use компілюються в CSS через gulp-sass.

⚡

Live reload

browser-sync підставляє нові стилі без перезавантаження і оновлює сторінку при зміні HTML.

🌐

Вендорні префікси

autoprefixer додає префікси згідно з browserslist у package.json.

✨

Стайлінг коду

stylelint перевіряє вихідний SCSS, prettier форматує як базовий код, так і кінцевий CSS.

📦

Мінімізація

cssnano створює style.min.css без пробілів і коментарів.

🚀

Запуск

npm install, потім npm start для розробки або npm run build для збірки.
